# 翻译提示

将 `website/architecture/` 下的 React Native 架构文档翻译为简体中文。目标读者是技术读者，译文应像中文技术文档一样自然，不做逐字直译。

要求：

- 保留原文的 Markdown、MDX、HTML、frontmatter、链接、代码块、diff、命令和图片引用。
- frontmatter 中保留 `id`、`slug` 等结构字段，新增 `sourceTitle` 保存原英文标题，并将 `title` 改为中文。
- 标题翻译为中文时保留原始 heading id，例如 `## 初始渲染`。
- API、代码标识符、组件名、包名、命令、路径、环境变量不翻译。
- 术语使用 `01-analysis.md` 中的术语表，保持全目录一致。
- 表达以准确、清晰、自然为优先，避免机器翻译腔。
