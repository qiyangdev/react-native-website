## 亮点

### 新动画后端

React Native 0.85 引入了新的共享动画后端，这是我们与 [Software Mansion](https://swmansion.com/) 合作构建的成果。

这是一个新的内部引擎，负责在底层驱动 Animated 和 Reanimated 的动画应用方式。通过把主要的动画更新逻辑移入 React Native 核心，Reanimated 能够落地过去无法实现的性能改进，并确保更新协调过程经过充分测试，在未来的 RN 更新中保持稳定。

在 Animated 中，你现在可以使用 native driver 为布局 props 设置动画（[这里曾经提到的限制](/docs/animations#caveats) 已不再适用）。

#### 如何为布局 props 设置动画

使用新的动画后端后，你将能够在 Animated 中使用 native driver 为 Flexbox 和位置相关 props 设置动画。

```jsx
import {
  Animated,
  Button,
  View,
  useAnimatedValue,
} from 'react-native';

function MyComponent() {
  const width = useAnimatedValue(100);

  const toggle = () => {
    Animated.timing(width, {
      toValue: 300,
      duration: 500,
      useNativeDriver: true,
    }).start();
  };

  return (
    <View style={{flex: 1}}>
      <Animated.View
        style={{width, height: 100, backgroundColor: 'blue'}}
      />
      <Button title="Expand" onPress={toggle} />
    </View>
  );
}
```

### React Native DevTools 改进

React Native DevTools 在这个版本中获得了多项改进：

- **多个 CDP 连接**：React Native 现在支持多个并发的 Chrome DevTools Protocol 连接，使 React Native DevTools、VS Code 和 AI agents 等客户端可以同时连接。这解锁了更丰富、可组合的工具工作流，而且不会意外结束会话。
- **macOS 原生标签页**：我们已将桌面应用更新为针对 macOS 26 编译，同时为高级用户启用了系统级标签页处理。打开多个 DevTools 窗口时，可以通过 **Window > Merge All Windows** 访问。

- **请求 payload 预览**：此前由于回归问题被禁用的 Network Panel 请求体预览，现在已在 Android 上恢复。

### Metro TLS 支持

Metro 开发服务器现在可以接收 TLS 配置对象，从而在开发期间启用 HTTPS（以及用于 Fast Refresh 的 WSS）。这对于测试强制要求安全连接的 API 很有用。

在 `metro.config.js` 中进行配置：

```js title="metro.config.js"
const fs = require('fs');

config.server.tls = {
  ca: fs.readFileSync('path/to/ca'),
  cert: fs.readFileSync('path/to/cert'),
  key: fs.readFileSync('path/to/key'),
};
```

对于本地开发，[mkcert](https://github.com/FiloSottile/mkcert) 是一种简单方式，可以生成本地受信任的证书，并避免浏览器警告。

## 破坏性变更

### Jest Preset 迁移到新包

React Native 的 Jest preset 已从 `react-native` 中抽离到新的 `@react-native/jest-preset` 包中，这会减小核心包体积，并让项目在测试配置上获得更多灵活性。

只需对 `jest.config.js` 做一行修改：

```diff title="jest.config.js"
- preset: 'react-native',
+ preset: '@react-native/jest-preset',
```

### 不再支持已 EOL 的 Node.js 版本

React Native 0.85 不再支持已终止生命周期（EOL）的 Node.js 版本，以及 v20.19.4 之前的版本。升级前请确保你正在运行受支持的 Node.js 版本。

- **Node.js v20**（>=20.19.4）— 受支持（Active LTS）
- **Node.js v21** — 不支持（EOL）
- **Node.js v22** — 受支持（Active LTS）
- **Node.js v23** — 不支持（EOL）
- **Node.js v24+** — 受支持

### 移除 `StyleSheet.absoluteFillObject`

已弃用的 `StyleSheet.absoluteFillObject` API 已被移除。请改用 `StyleSheet.absoluteFill`，或自行定义绝对定位样式。

```diff
- const styles = StyleSheet.absoluteFillObject;
+ const styles = StyleSheet.absoluteFill;
```

### 其他破坏性变更

#### 通用

- `Pressable` 不再卸载隐藏 `Activity` 中的事件监听器。
- 移除了 `ShadowNode::Shared`、`ShadowNode::Weak`、`ShadowNode::Unshared`、`ShadowNode::ListOfWeak`、`ShadowNode::ListOfShared`、`SharedImageManager` 和 `ContextContainer::Shared` 等已弃用的 C++ 类型别名。这些别名没有被使用，消费方库应直接使用对应类型。

#### Android

- 我们将 `receiveTouches` 重新加入 `RCTEventEmitter`，并提供默认的 no-op 实现。这项修复可以减少尚未迁移出该方法的库所遇到的破坏性变更。
- `ReactTextUpdate` 现在是内部 API，不应再被公开直接访问。
- 作为旧架构清理的一部分，多个类已弃用或移除：
  - `ReactZIndexedViewGroup` 现已弃用。
  - `UIManagerHelper` 现已弃用。
  - `CatalystInstanceImpl` 已被移除（此前已弃用）。
  - `NativeViewHierarchyManager` 已被完全 stub 化。

#### iOS

- `RCTHostRuntimeDelegate` 现已弃用，并合并入 `RCTHostDelegate`。
- 修复了使用 `React.XCFramework` 时的重复符号错误（通过将 `fmt` 升级到 12.1.0）。

## 其他变更

- **Metro** 升级到 `^0.84.0`。
- **React** 更新为使用 Hermes `250829098.0.10`。
- **Yoga**：Android 上的 `YogaNode` 已迁移到 Kotlin。
- **无障碍**：弃用 `AccessibilityInfo.setAccessibilityFocus`，改用 `AccessibilityInfo.sendAccessibilityEvent`。
- **TypeScript**：多个工具类型转换（`$Values`、`mixed`、`$ReadOnly`、`$ReadOnlyArray`）。
- **Android 构建**：允许通过 `reactNativeDevServerIp` Gradle 属性指定开发服务器 IP。
- **iOS 构建**：为 `React.XCFramework` 增加了 clang 虚拟文件系统支持。

## 升级到 0.85

:::info

0.85 现在是 React Native 的最新稳定版本，0.82.x 则转为不受支持。更多信息请参阅 [React Native 支持政策](https://github.com/reactwg/react-native-releases/blob/main/docs/support.md)。

#### 升级

对于现有项目，请使用 [React Native Upgrade Helper](https://react-native-community.github.io/upgrade-helper/) 查看不同 React Native 版本之间的代码变更，同时也可参考[升级文档](/docs/upgrading)。

#### 创建新项目

```sh
npx @react-native-community/cli@latest init MyProject --version latest
```

#### Expo

如果你使用 Expo，下一个 SDK（SDK 56）将包含 React Native 0.85。
